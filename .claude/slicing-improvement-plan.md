# 切片优化方案讨论记录 (2026-03-25)

## 背景问题
全量 benchmark v7 结果: R=98.7% 但 P=52.6%，FP 最大来源是**跨切片重复提取**。
同一产品在重叠切片中被多次提取，去重链无法完全合并 → P 大幅下降。

## 页面图片数据的三种构成

| 场景 | PDF 结构 | fitz 能力 | YOLO 能力 |
|------|----------|-----------|-----------|
| A: 多张独立嵌入图 | 30 张独立图片对象 | 精确拿到 30 个 bbox ✓ | 不需要 |
| B: 1 张大拼图 | 1 张图含多个产品 | 只看到 1 张图 ✗ | 能检测出多个产品区域 ✓ |
| C: 扫描版 | 整页是 1 张图 | 只看到 1 张图 ✗ | 能检测产品区域 ✓ |

IMG_DENSE 页大多是场景 A（多张独立图片）。

## 当前方案（均匀切片）

```
fitz 元数据 → 网格检测 (行×列) → 按页面高度均匀切 N 刀
→ 固定 120pt 重叠 → 每片送 LLM
→ 事后跨切片去重（补救）
```

**问题**:
- 均匀切割不关心图片实际位置，可能切在产品中间
- 固定重叠区导致边界产品被两个切片都提取 → 大量重复
- 去重依赖名称相似度，LLM 对同产品生成不同名称时去重失败

## 更优方案: bbox 精确切片

### 核心思路
"看图片在哪，沿着图片间隙切"，而非均匀切。

### 融合策略
```
fitz 元数据 (有多个独立图片 bbox？)
    ├─ 是 (场景A) → 直接按 bbox 聚类切片，无需 YOLO
    └─ 否 (场景B/C: 1-2 张大图/扫描版)
         → YOLO 检测产品区域
         → 按检测 bbox 切片
```

### 对比

| | 当前均匀切 | bbox 精确切 |
|---|---|---|
| 切割位置 | 按页面高度等分 | 按图片间隙 |
| 重叠 | 固定 120pt → 产品重复 | 无重叠 → 无重复 |
| 每片产品数 | 不可控 | 精确可控 (3-5个/片) |
| 信息来源 | 网格行列数 | 实际 bbox 坐标 |

### 产品多图聚合（同一产品包含多张图的聚合方案）

**层级1: 网格单元格聚合（最简，优先实施）**
- 利用已有 `_detect_grid` 的行列信息
- 按网格单元格划分，每个 cell 内所有图片归为一组
- 零额外成本，IMG_DENSE 大多是规则网格

**层级2: 空间邻近聚类**
- 两张图间距 < min(较小图尺寸) × 0.5 → 归为同一产品
- 适用于非规则布局

**层级3: 主图+附图模式识别**
- 面积最大 = 主图，面积 < 主图 30% 且紧邻 = 色卡/细节图
- 大图+旁边小图 → 同产品；大图+大图 → 不同产品

**层级4: 文字锚点关联**
- fitz 提取文字块坐标，产品名/型号在图片正下方
- 图片 + 正下方文字块 = 一个产品区域

## 实施优先级

1. **层级1: 网格单元格精确切片** — 改动最小，只改 `page_slicer.py`，消除 IMG_DENSE 的切片重叠
2. **融合 YOLO**: 对场景 B/C 补充 YOLO bbox 检测辅助切片
3. **层级2-4**: 按需渐进增强
