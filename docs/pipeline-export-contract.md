# Pipeline 导出契约

## 1. 主工作表字段顺序

主工作表必须按以下顺序输出字段，不允许调换顺序：

1. 商品图片
2. 规格图片
3. 商品名称/描述
4. 售价
5. 货号
6. 商品ID
7. 标签
8. 来源(仅自己可见)
9. 商品简称
10. 商品规格
11. 颜色
12. 规格编码
13. 批发价
14. 打包价
15. 代发价
16. 拿货价(仅自己可见)
17. 活动类型
18. 活动价
19. 库存
20. 重量(kg)
21. 备注(公开)
22. 自动下架时间

约束：

- 未识别出的字段必须保留空值
- 不允许删列
- 不允许改名

## 2. 首版重点识别字段

首版必须重点识别并尽力抽取以下字段：

- 商品名称/描述
- 售价
- 商品规格
- 颜色
- 批发价
- 打包价
- 代发价
- 活动价
- 库存
- 重量(kg)
- 自动下架时间

其余字段：

- 可以作为保留字段存在
- 当前无法识别时允许留空

## 3. 属性抽取原则

属性处理遵循以下顺序：

1. 先尽可能提取完整的属性相关文本
2. 先写入“商品名称/描述”或商品描述语义容器
3. 再从中抽离结构化字段

这意味着：

- 不要求第一步就把所有字段结构化
- 原始属性文本应尽量保留
- 结构化抽取失败时，描述字段仍应尽量保留有效信息

## 4. 图片列展开规则

由于同一商品可能有多张商品图片，所以允许重复多个“商品图片”列。

规则：

- 列名必须保持为“商品图片”
- 允许重复的只有“商品图片”列
- 其它列不允许重复
- 其它列不允许改名

顺序要求：

- 多个“商品图片”列应排在最前面
- 然后继续按主工作表字段顺序输出后续字段
- “规格图片”之后的字段顺序保持不变

当前首版约定：

- `规格图片` 列默认留空
- 第一版不主动从细节图中再识别或填充“规格图片”

## 5. 图片写入方式

图片必须直接嵌入 Excel。

不允许：

- 只写文本路径
- 只写图片 URL
- 把多张图片拼接成单个单元格文本

当前默认导出边界：

- 保留筛选后的全部相关图片
